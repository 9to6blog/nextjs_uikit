TUNE THE FEELING

Every millisecond matters.

Duration240 ms

정보와 기능은 그대로.

시스템에서 모션 감소가 켜져 있다면 이 설정과 관계없이 움직임을 줄입니다.

One motion language

200 msRespond

버튼 피드백, 메뉴 닫힘

300 msConnect

탭 이동, 상태 전환

500 msReveal

큰 표면, 진행률 변화

CSS
--n-duration-fast: 200ms;
--n-duration-normal: 300ms;
--n-duration-slow: 500ms;
--n-ease: cubic-bezier(.22, 1, .36, 1);
--n-ease-exit: cubic-bezier(.4, 0, 1, 1);

Respect the user

운영체제의 prefers-reduced-motion을 우선합니다. 앱 설정에서도 모션 감소를 선택할 수 있습니다. 상태와 정보는 애니메이션이 꺼져도 동일하게 유지됩니다.

tsx
<UIProvider motion="reduced">
  {children}
</UIProvider>
