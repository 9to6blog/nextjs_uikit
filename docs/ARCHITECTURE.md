# Architecture

## Dependency boundaries

`packages/ui/src` is the source of truth. TypeScript emits one ESM module and declaration per source file, preserving client directives. Static components do not import interactive dependencies. Next.js-specific adapters are `nav-link` and `submit-button`. Radix provides maintained accessibility and interaction primitives; the library owns presentation, API composition, tokens and motion.

Advanced engines are used explicitly: TanStack Table v8, Recharts, DayPicker, Embla, cmdk, input-otp, react-resizable-panels, dnd-kit, Vaul and Sonner. The package has these installation dependencies, but individual imports allow the application bundler to exclude unused JavaScript. This is a bundler property to verify, not a promise of zero JavaScript for interactive pages.

## Rendering and themes

`UIProvider` wraps server children without requiring their modules to be client components. Theme attributes are replicated onto portaled surfaces. Palette and motion tokens are scoped to `data-n-ui`; an application can override them with a matching CSS selector. Portal-specific inline styles remain configurable on each content component.

Motion uses bounded CSS transitions and keyframes. `useReducedMotion` merges the OS preference with provider policy for JavaScript animation engines. Server snapshots prefer reduced motion until hydration establishes the actual setting. It never blocks rendering while waiting for hydration.

## Distribution

- ESM tarball: emitted modules, declarations, original source, CSS and notices.
- Shadcn registry: transitive local source dependencies and exact upstream dependency ranges, generated by `scripts/build-registry.mjs`.
- Documentation: Next.js App Router static export, with dynamic imports per demonstration group. No production API, credentials or persistence service is required.
- No npm publish, public-site deployment or blog integration happens as part of local builds.

The documentation build also normalizes the segment prefetch filenames emitted by Next.js 16.3.5 on Windows. `scripts/normalize-export.mjs` adds static aliases for the dot-separated URLs requested by the client; it preserves the original files and refuses conflicting aliases. The output remains usable on an ordinary static host. Browser checks exercise real client navigation and reject failed resource responses.

## Performance constraints

Documentation is static and can use CDN caching. A consumer app should keep content server-rendered and import interactive controls only where needed. Large datasets require app-level server pagination or virtualization. Monthly visits and simultaneous users are not a meaningful UI-only capacity test; real server capacity depends on the consuming app's data, authentication, caching, media and database workload.
