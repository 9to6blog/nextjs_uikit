Semantic tokens

모든 스타일은 n- 접두사와 data-n-ui 범위 안에 있습니다. 기존 앱의 전역 CSS를 초기화하지 않습니다.

--n-bg
--n-surface
--n-raised
--n-text
--n-muted
--n-accent
--n-success
--n-warning
--n-danger
CSS
/* 특정 테마 범위에서 토큰을 재정의합니다. */
[data-n-ui][data-theme="light"] {
  --n-accent: #0a0a0a;
  --n-accent-hover: #262626;
  --n-accent-soft: #f5f5f5;
  --n-accent-ink: #171717;
  --n-on-accent: #ffffff;
  --n-radius: 8px;
  --n-height: 36px;
}

세 가지 기본 약속

  • 색상은 성공·경고·오류 등 의미에 따라 사용합니다.
  • 포커스는 색상만으로 구분하지 않고 외곽선으로 표시합니다.
  • 터치·키보드·마우스에서 같은 작업을 수행할 수 있게 설계합니다.

사용자 정의 팔레트는 별도 대비 검증이 필요합니다. 예제 프리셋의 검증 범위는 지원 범위 페이지에서 확인할 수 있습니다.
