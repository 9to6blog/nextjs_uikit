STUDIO ANALYTICS

선 차트

데이터로 바꾸어 사용하기

각 유형에 같은 data와 series를 전달합니다. 파이·도넛·방사형은 첫 번째 시리즈를 사용하고, 산점도는 xKey의 숫자 값과 각 시리즈의 값을 짝지어 표시합니다. 범례와 접을 수 있는 데이터 표를 함께 제공합니다.

tsx
"use client";
import {ChartView} from "@9to6/ui/chart-view";
import "@9to6/ui/styles.css";

const data = [
  {
    "name": "월",
    "visitors": 120,
    "returning": 42,
    "x": 1
  },
  {
    "name": "화",
    "visitors": 180,
    "returning": 56,
    "x": 2
  },
  {
    "name": "수",
    "visitors": 145,
    "returning": 61,
    "x": 3
  },
  {
    "name": "목",
    "visitors": 240,
    "returning": 89,
    "x": 4
  },
  {
    "name": "금",
    "visitors": 210,
    "returning": 76,
    "x": 5
  },
  {
    "name": "토",
    "visitors": 285,
    "returning": 104,
    "x": 6
  }
];
const series = [
  {
    "key": "visitors",
    "label": "방문자"
  },
  {
    "key": "returning",
    "label": "재방문"
  }
];

export default function Analytics() {
  return <ChartView kind="line" label="작업실 방문 추이" data={data} series={series} xKey="x" height={320} />;
}

시리즈별 색상은 color로 지정합니다. 더 세밀한 구성은 @9to6/ui/chart의 개별 차트 요소를 조합하세요. 예시는 동작 확인을 위한 가상 방문 데이터입니다.
