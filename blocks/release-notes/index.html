조금씩 더 좋아지는 작업실

업데이트 화면 구성을 위한 예시 기록입니다.

  1. 0.3.02026-09-20

    기록을 찾는 새로운 방법

    • 주제별로 글을 모아 볼 수 있습니다.
    • 검색 결과에서 읽기 시간을 확인합니다.
  2. 0.2.02026-09-12

    함께 다듬는 초안

    • 검토할 항목을 체크리스트로 정리합니다.
    • 작업 상태를 보드에서 옮길 수 있습니다.
  3. 0.1.02026-09-01

    첫 번째 작업실

    • 프로필과 글 목록을 공개합니다.

이 블록 사용하기

패키지의 독립 경로로 가져옵니다. Next.js와 React 모두 같은 블록을 사용하며, 데이터 저장과 서버 요청은 앱의 콜백에 연결합니다.

tsx
// Next.js: app/layout.tsx · React: 앱 진입 파일
import "@9to6/ui/styles.css";
import "@9to6/ui/blocks.css";

블록 컴포넌트 소스
blocks/release-notes.tsx
import { Badge } from "../badge.js";
import { BlockShell, type BlockProps } from "./shared.js";
export type ReleaseNotesProps = BlockProps & {
  releases: {
    version: string;
    date: string;
    title: string;
    changes: string[];
  }[];
};
export function ReleaseNotes({ releases, ...props }: ReleaseNotesProps) {
  return (
    <BlockShell {...props}>
      <ol className="n-block-releases">
        {releases.map((r) => (
          <li key={r.version}>
            <div>
              <Badge>{r.version}</Badge>
              <time dateTime={r.date}>{r.date}</time>
            </div>
            <section>
              <h3>{r.title}</h3>
              <ul>
                {r.changes.map((c) => (
                  <li key={c}>{c}</li>
                ))}
              </ul>
            </section>
          </li>
        ))}
      </ol>
    </BlockShell>
  );
}

예제에 있는 block-demo-* 클래스는 문서 안내용입니다. 블록의 스타일은 blocks.css에 포함됩니다. 소스를 직접 복사할 때는 같은 폴더의 shared 모듈도 함께 가져오세요.
